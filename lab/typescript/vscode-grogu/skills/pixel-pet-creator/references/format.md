# 形式リファレンス

## pet.js（ペットの定義）

`build-pet.js` が読み込む定義ファイル。次の形のオブジェクトを `module.exports` する。

```js
module.exports = {
  name: 'もち',        // 表示名（省略時はフォルダ名）
  frameWidth: 40,      // 1コマの幅（ドット）
  frameHeight: 44,     // 1コマの高さ（ドット）
  originX: 8,          // 描画座標の原点（省略時 0）
  originY: 13,
  sideMargin: 8,       // 本体の左右の余白（ドット）。このぶんは画面端からはみ出して歩ける（省略時 0）
  displayWidth: 120,   // 表示幅（CSSピクセル）。省略時は frameWidth の3倍
  float: false,        // true にすると、待機中にふわふわ上下に揺れる
  scale: 4,            // 出力PNGの拡大率（省略時 4）
  animations: {
    idle: {
      kind: 'idle',
      frames: [
        { d: 1600, draw: (c) => { /* 1コマ目を描く */ } },
        { d: 120, draw: (c) => { /* 2コマ目を描く */ } },
      ],
    },
    // ...
  },
};
```

### アニメーションの項目

| 項目 | 必須 | 内容 |
|------|------|------|
| `kind` | ○ | 役割。下の表を参照 |
| `frames` | ○ | コマの配列。各コマは `{ d: 表示時間ミリ秒, draw: (c) => {...} }` |
| `repeat` | | 何回繰り返してから待機に戻るか（省略時 1）。居眠りなど、長く続けたい演技に使う |
| `on` | | 再生するきっかけの配列。下の「きっかけ」を参照 |
| `onChance` | | きっかけが起きたときに再生する確率 0〜1（省略時 1） |
| `chance` | | `secret` が待機明けに出る確率 0〜1（省略時 0.03） |
| `travel` | | `true` なら、その絵のまま画面の遠いほうの端まで移動する。乗り物向け |
| `speed` | | `travel` のときの、歩く速さに対する倍率（省略時 1） |

アニメーション名は英小文字・数字・ハイフンで付ける。

### kind（役割）

| kind | いつ再生されるか |
|------|------|
| `idle` | 立ち止まっている間、ループ再生。**必須**。複数あればランダムに選ばれる |
| `walk` | 歩いている間、ループ再生。**必須**。右向きで描く |
| `walk-left` | 左へ歩く間。省略すると `walk` を左右反転して使う。左右非対称のキャラクター向け |
| `action` | 待機の合間に、ランダムで再生 |
| `reaction` | `on` で指定したきっかけでだけ再生（ランダムには出ない） |
| `secret` | 待機明けに `chance` の確率で再生。ペットを素早く5回クリックしても出る |

`action` と `secret` にも `on` を付けられる（ランダムにも、きっかけでも出る）。

### きっかけ（`on` に指定できる値）

| 値 | 起きるとき |
|------|------|
| `click` | ペットをクリックした。指定が無ければ、その場でジャンプする |
| `save` | ファイルを保存した |
| `error` | エラーの数が増えた |
| `errorsCleared` | エラーがゼロになった |
| `success` | タスク、またはビルド・テスト系のターミナルコマンドが成功した |
| `fail` | タスク、またはターミナルコマンドが失敗した |
| `taskStart` | タスクが始まった |
| `debugStart` | デバッグが始まった |
| `debugEnd` | デバッグが終わった |
| `typing` | しばらく入力が続いている |
| `away` | しばらく操作が無い（既定で5分） |
| `back` | 離席から戻った |

- 同じきっかけには、6秒間は続けて反応しない。
- 保存や入力のように頻繁に起きるものは、`onChance` を 0.3〜0.5 にして、うるさくならないようにする。
- `away` で始めた演技は、操作が戻ると自動で中断される。

## ビルドの出力

```
<ペットのフォルダ>/
  pet.js              定義（自分で書く）
  manifest.json       アニメーションの一覧（自動生成）
  idle.png ...        コマを横一列に並べたスプライトシート（自動生成）
  _preview/           目視確認用の拡大画像（自動生成。拡張機能は読まない）
```

拡張機能が読むのは `manifest.json` と、そこに書かれた PNG だけ。

## manifest.json を手で書く場合

絵を別の道具で描いた場合は、`pet.js` を使わず、PNG と `manifest.json` を直接置いてもよい。
PNG は、同じ大きさのコマを横一列に並べる。

```json
{
  "format": 1,
  "name": "My Pet",
  "frameWidth": 48,
  "frameHeight": 48,
  "displayWidth": 144,
  "sideMargin": 0,
  "float": false,
  "animations": {
    "idle": { "file": "idle.png", "kind": "idle", "frames": 4, "delays": [1600, 120, 900, 120] },
    "walk": { "file": "walk.png", "kind": "walk", "frames": 6, "delay": 120 },
    "cheer": { "file": "cheer.png", "kind": "reaction", "frames": 5, "delay": 150, "on": ["success"] }
  }
}
```

`frameWidth` / `frameHeight` はコマの縦横比を決めるための値で、画像の実寸は何倍でもよい。
表示時間は `delays`（コマごと）か `delay`（全コマ共通）で指定する。
そのほかの項目（`repeat` `on` `onChance` `chance` `travel` `speed`）は `pet.js` と同じ。

## Codex 形式のペット

フォルダに Codex アプリ用の `pet.json` とアトラス画像（8列×9行、1マス 192×208）があれば、そのまま読み込める。
9つの状態は次のように割り当てられる。

| Codex の状態 | 割り当て |
|------|------|
| `idle` | 待機 |
| `running-right` / `running-left` | 右 / 左への歩行 |
| `waving` | ランダムな演技、クリックへの反応 |
| `jumping` | 成功、エラー解消への反応 |
| `failed` | 失敗、エラーへの反応 |
| `waiting` | ランダムな演技、離席への反応 |
| `running` | タスク開始、デバッグ開始への反応 |
| `review` | ランダムな演技、保存への反応（確率 0.5） |

同じフォルダに `manifest.json` も置くと、Codex の9状態を土台に、アニメーションを追加・上書きできる。
この場合、追加するコマの大きさは 192×208 にそろえる（`frameWidth` / `frameHeight` は省略できる）。

# 描画ガイド

`pet.js` の各コマは `draw(c)` 関数で描く。`c` は1コマ分のキャンバス。

## キャンバスのAPI

色は `'#rrggbb'` の文字列で指定する。`null` を渡すと、その部分を透明に戻す。
座標は左上が原点で、右が +x、下が +y。

| メソッド | 内容 |
|------|------|
| `c.px(x, y, color)` | 1ドット塗る |
| `c.rect(x0, y0, x1, y1, color)` | 矩形を塗る（両端を含む） |
| `c.ellipse(cx, cy, rx, ry, color)` | 楕円を塗る |
| `c.polygon([[x, y], ...], color)` | 多角形を塗る |
| `c.points([[x, y], ...], color)` | 複数のドットを塗る |
| `c.line(x0, y0, x1, y1, color)` | 直線を引く |
| `c.outline(color)` | ここまでに描いた絵の外周に、1ドットの輪郭線を付ける |
| `c.filled(x, y)` | そのドットが塗られているか |

後から描いたものが上に重なる。奥にあるものから順に描く。

### 原点をずらして余白を作る

`pet.js` の `originX` / `originY` を指定すると、座標の原点がそのぶん右下にずれる。
キャラクター本体を `(0, 0)` 付近から描き、左右や上に小道具・ジャンプ用の余白を確保できる。

```js
module.exports = {
  frameWidth: 40,   // コマの幅
  frameHeight: 44,  // コマの高さ
  originX: 8,       // 左に8ドットの余白
  originY: 13,      // 上に13ドットの余白
  sideMargin: 8,    // 本体の左右にある余白。このぶんは画面端からはみ出して歩ける
  ...
};
```

余白にはマイナスの座標で描ける（例: 頭上の風船は `y = -5`）。

## 基本の組み立て方

**ポーズを引数で変えられる描画関数を1つ書き、全コマでそれを使い回す。**
コマごとに絵を書き起こすと、コマ間で形がぶれるうえ、あとで直すのが大変になる。

```js
function drawPet(c, pose = {}) {
  const { lift = 0, eyes = 'open', prop, fx } = pose;
  // 1. 体（奥のものから）
  // 2. 顔
  // 3. 小道具
  if (prop) prop(c);
  // 4. 輪郭
  c.outline(OUTLINE);
  // 5. 輪郭を付けたくないエフェクト（光・火花・煙）
  if (fx) fx(c);
}

const frame = (d, pose) => ({ d, draw: (c) => drawPet(c, pose) });

// アニメーションは、ポーズの並びとして書ける
frames: [frame(1600, {}), frame(120, { eyes: 'closed' })]
```

引数にしておくと便利なもの:

- 体全体の上下（`lift`）、つぶれ・伸び（`squish`）、横ずれ（震え用）
- 目（開く・閉じる・笑う・驚く）、口
- 腕や耳など、動かす部位ごとのポーズ
- `prop`（輪郭が付く小道具）と `fx`（輪郭が付かないエフェクト）

手本の `examples/mochi/pet.js` が、この形で書かれている。

## 絵を良くするコツ

### 大きさと比率

- コマは 32〜48 ドット四方が扱いやすい。大きくするほど描く量が増え、粗が目立つ。
- 本体はコマの中央下寄りに置き、**足元の高さを全コマでそろえる**。足が浮き沈みすると滑って見える。
- 頭を大きく、体を小さくすると、かわいく幼く見える。目は顔の下寄りに、大きめに置く。
- **輪郭は最後に 1 ドット外側へ付く。** キャンバスの端から 1 ドットは空けておく。

### 形

- まずシルエットを決める。塗りつぶしただけでそのキャラクターと分かるのが理想。
- 特徴は誇張する。耳が大きいキャラクターなら、実物よりさらに大きく太く描く。
- 楕円の半径は 0.5 刻みで試す。てっぺんに 1 ドットだけ飛び出すとトゲに見えるので、
  半径や中心を少しずらして、頂点が 3 ドット以上の幅になるようにする。
- 中心を `11.5` のように `.5` にすると偶数幅になり、目などを左右対称に置ける。
- 胴体を長方形だけで描くと箱に見える。台形（`polygon`）にして、角を落とす。
- 腕を横に付け足すと胴が四角く広がる。体の輪郭に沿わせるか、境目の影の線だけで表す。

### 色

- 1体あたり 8〜12 色に抑える。各色に、少し暗い影色を1つ用意すると立体感が出る。
- 輪郭は真っ黒より、濃い茶や濃紺のほうがなじむ。
- 白い部分は、明るい背景でも見えるよう必ず輪郭の内側に置く。
- 参考画像があるなら、色は画像から拾う。記憶の印象より、実物はくすんでいることが多い。

### 顔

- 小さな絵では、目・眉・口の位置が 1 ドット違うだけで別人になる。似ないときは、まずここを疑う。
- 黒目の左上に白を 1 ドット入れると、生きた目になる。
- 口と鼻を両方描くと潰れる。どちらかを省く。
- 閉じた目は横線、笑った目は「＾」の形に並べる。

### エフェクト

- 光の粒・火花・煙などの小さな点は、輪郭が付くと黒い塊になる。`c.outline()` の後（`fx`）に描く。
- 逆に、小道具（食べ物・道具・乗り物）は輪郭の前（`prop`）に描いて、本体と同じ線で囲む。

## 動きのコツ

### 表示時間（`d`、ミリ秒）の目安

| 動き | 1コマの長さ |
|------|------|
| 歩行・震え・火花 | 90〜180 |
| ふつうの動作 | 180〜300 |
| 溜め・見つめる・余韻 | 400〜800 |
| 待機の静止 | 1500〜2500 |
| まばたき | 100〜150 |

全コマを同じ長さにしない。**溜めて、素早く動き、余韻を残す**と生き生きする。

### 動かし方

- **つぶしと伸ばし**: 跳ぶ前に縦につぶし、空中で縦に伸ばし、着地でまたつぶす。
- **体の上下**: 歩行は、足を上げるコマで体を 1 ドット持ち上げるだけでも歩いて見える。
- **遅れてついてくる部位**: 耳・しっぽ・葉っぱなどは、体より 1 コマ遅れて動かす。
- **表情を変える**: 驚く（目を見開く）→ 行動 → 喜ぶ（目を細める）と、同じ動きでも物語になる。
- **始まりと終わりを立ち姿に近づける**: 待機から自然につながる。

### 演技の組み立て

1. 気づく（目を見開く、小道具が現れる）
2. 動く（手を伸ばす、近づく）
3. 山場（食べる、光る、感電する）
4. 余韻（喜ぶ、ぐったりする）

4〜12 コマ、合計 2〜5 秒がちょうどよい。

### 向き

絵は**右向き**で描く。左へ進むときは、拡張機能が自動で左右反転する。
小道具は本体の右側に置く（演技中は必ず右向きで再生される）。

## よくある失敗

| 症状 | 原因と直し方 |
|------|------|
| 絵が端で切れる | コマを大きくするか、`originX` / `originY` で余白を増やす |
| 歩くと上下に滑る | コマ間で足元のY座標がずれている。地面の高さを定数にする |
| 光や星が黒い塊になる | `c.outline()` の前に描いている。`fx` に移す |
| 体が箱に見える | 長方形を台形に変え、角を落とす |
| 頭のてっぺんが尖る | 楕円の頂点が 1 ドットになっている。半径か中心を調整する |
| 似ていない | 特徴の誇張が足りない。耳・目・眉など、決め手の部位から直す |
| 小道具が何か分からない | 小さすぎる。5〜7 ドット四方は使い、色を本体と離す |

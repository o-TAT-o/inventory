# Pixel Pal

VS Code のエクスプローラーに、好きなドット絵ペットを表示する拡張機能です。

- **ペットを差し替えられる**: ペットは「1フォルダ＝1体」の素材です。フォルダを指定するだけで、自作のキャラクターに変えられます。
- **AI でペットを作れる**: ペット作成用のスキル（AIエージェント向けの手順書とツール）を同梱しています。お使いの AI に「ペットを作って」と頼めば、素材ができあがります。
- **エディタに反応する**: 保存、エラー、ビルドやテストの成否、離席などに合わせて演技をします。
- **レア演出がある**: めったに出ないシークレット演出を、ペットごとに定義できます。

> フォルダ名は開発当初の名残で `vscode-grogu` のままです。

## 使い方

### 起動（開発中）

```sh
npm install
npm run compile
```

このフォルダを VS Code で開いて `F5` を押し、開いたウィンドウでエクスプローラー下部の「Pixel Pal」ビューを展開します。
初期状態では、同梱のサンプルペット「もち」が表示されます。

ビューの高さは境界線のドラッグで変えられます。ビューのタイトルをドラッグすれば、下部パネルやセカンダリサイドバーにも移せます。

### ペットとの遊び方

- 何もしなければ、歩く・立ち止まる・演技をする、を気ままに繰り返します。
- パネルをクリックすると、その位置まで歩いてきます。
- ペットをクリックすると反応します。
- ペットを2秒以内に5回クリックすると、シークレット演出が出ます。

### コマンド

コマンドパレット、またはビュー右上の「…」メニューから実行できます。

| コマンド | 内容 |
|------|------|
| Pixel Pal: ペットを選ぶ | 表示するペットを一覧から選ぶ。任意のフォルダも指定できる |
| Pixel Pal: アニメーションを再生（確認用） | 指定したアニメーションをその場で再生する |
| Pixel Pal: ペットを読み込み直す | 素材を読み込み直す |
| Pixel Pal: ペット作成スキルをワークスペースに導入 | AIエージェント用のフォルダにスキルをコピーする |

「ペットを選ぶ」の一覧には、次の場所にあるペットが出ます。

- 拡張機能に同梱のペット
- `~/.pixel-pal/pets/` に置いた自作のペット
- `~/.codex/pets/` にある Codex アプリのカスタムペット

### 設定

| 設定 | 既定値 | 内容 |
|------|------|------|
| `pixelPal.petPath` | 空（同梱の `mochi`） | 表示するペットのフォルダ。絶対パス、`~/` から始まるパス、ワークスペース相対パス、同梱ペットの名前 |
| `pixelPal.scale` | `1` | 表示倍率 |
| `pixelPal.reactToEditor` | `true` | エディタ上の出来事に反応するか |
| `pixelPal.awayMinutes` | `5` | 操作が無い状態が何分続いたら「離席」とみなすか |

## AI でペットを作る

1. ペットを作りたいワークスペースで、**「Pixel Pal: ペット作成スキルをワークスペースに導入」** を実行します。
   Claude Code、GitHub Copilot、Codex など、使っている AI エージェントに合わせて導入先を選びます。
2. AI エージェントに頼みます。

   > 丸っこい柴犬のペットを作って。骨をかじる演技と、テストが通ったら喜ぶ動きを入れて。

3. AI が `~/.pixel-pal/pets/<名前>/` に素材を作ります。
4. **「Pixel Pal: ペットを選ぶ」** で、できたペットを選びます。

スキルは、AI が JavaScript でドット絵を描き、出力画像を自分で見て直す、という手順になっています。
画像生成モデルは使いません。素材を作り直すと、ビューには自動で反映されます。

スキルの中身は [skills/pixel-pet-creator/](skills/pixel-pet-creator/) にあります。

| ファイル | 内容 |
|------|------|
| [SKILL.md](skills/pixel-pet-creator/SKILL.md) | AI 向けの手順 |
| [references/drawing-guide.md](skills/pixel-pet-creator/references/drawing-guide.md) | 描画 API と、ドット絵をうまく描くコツ |
| [references/format.md](skills/pixel-pet-creator/references/format.md) | 素材の形式、きっかけの一覧 |
| [examples/mochi/pet.js](skills/pixel-pet-creator/examples/mochi/pet.js) | サンプルペット「もち」の定義 |
| `scripts/` | 素材をビルドするツール（Node.js のみで動作） |

既存の作品のキャラクターをペットにした場合、その素材はファンアートにあたります。個人で楽しむ範囲にとどめてください。

## ペットの形式

ペットのフォルダには、`manifest.json` と、アニメーションごとのスプライトシート（コマを横一列に並べた PNG）を置きます。

アニメーションには役割があります。

| 役割 | いつ再生されるか |
|------|------|
| `idle` | 立ち止まっている間（必須） |
| `walk` | 歩いている間（必須） |
| `action` | 待機の合間に、ランダムで |
| `reaction` | 保存・成功・失敗など、指定したきっかけで |
| `secret` | ごくまれに。乗り物に乗って移動する演出も作れる |

項目の詳細と、きっかけの一覧は [format.md](skills/pixel-pet-creator/references/format.md) を参照してください。

### エディタ連携のきっかけ

`click`、`save`、`error`、`errorsCleared`、`success`、`fail`、`taskStart`、`debugStart`、`debugEnd`、`typing`、`away`、`back`

ターミナルコマンドの成否は、VS Code のシェル統合が有効なときに検知します。
成功に反応するのは、ビルドやテストらしいコマンド（`test`、`build`、`tsc`、`pytest` など）に限っています。

### Codex 形式との互換

Codex アプリのカスタムペット（`pet.json` と 8列×9行のアトラス画像）も、そのまま読み込めます。
9つの状態は、待機・歩行・各きっかけへの反応に自動で割り当てられます。
同じフォルダに `manifest.json` を置けば、Codex のペットに演技やシークレット演出を追加できます。

実際の Codex 製ペットでの表示は未検証です。仕様書に基づく実装で、確認したのは読み込み処理までです。

## 開発

| パス | 役割 |
|------|------|
| `src/extension.ts` | ビューの登録、設定、コマンド |
| `src/petLoader.ts` | ペットのフォルダの読み込みと検証（独自形式・Codex 形式） |
| `src/editorEvents.ts` | エディタ上の出来事の検知 |
| `media/main.js` | ビュー内でのペットの動きの制御 |
| `media/main.css` | レイアウトと CSS アニメーション |
| `pets/mochi/` | 同梱のサンプルペット（ビルド済み） |
| `skills/pixel-pet-creator/` | ペット作成スキル |

サンプルペットを作り直すには、次を実行します。

```sh
npm run pet:sample
```

`pets/` 配下は `mochi` 以外を `.gitignore` で除外しています。公開しないローカル専用のペットを置けます。

# vscode-grogu

VS Code のエクスプローラーにグローグーを表示する拡張機能です。
エクスプローラーを開いている間、Grogu ビューの中で歩いたり演技をしたりします。

> **キャラクター素材について**
> スプライト画像（`media/sprites/`）と、絵を定義している生成スクリプト（`scripts/generate-sprites.js`）は、
> 既存キャラクターのファンアートにあたるため、このリポジトリには含めていません。
> 素材が無い状態で起動すると、ビューには案内メッセージだけが表示されます。
> 動かすには、下記「スプライトの形式」に沿った素材を `media/sprites/` に置いてください。

## セットアップ

```sh
npm install
npm run compile
```

## 動き

- 何もしなければ、歩く・立ち止まる・演技をする、を気ままに繰り返します。
- パネルをクリックすると、その位置まで歩いてきます。
- グローグーをクリックするとジャンプします。演技中なら中断します。

| アニメーション | 内容 |
|------|------|
| `idle` | 立ち止まってまばたきする |
| `walk` | 歩く |
| `frog` | カエルを捕まえて食べる |
| `wires` | 配線をいじって感電する |
| `force` | フォースで銀の玉を浮かせようとする |
| `sleep` | 立ったまま居眠りする |
| `cookie` | 青いマカロンを食べる |

### シークレット演出

ごくまれに（待機明けの約4%）出る特別な演出です。
グローグーを2秒以内に5回クリックすると、順番に1つずつ確実に出せます。

| アニメーション | 内容 |
|------|------|
| `shield` | 銀の盾を拾って構える |
| `robot` | 二足歩行ロボットの操縦席に乗って歩く |
| `pram` | 宙に浮くゆりかごに乗って移動する |

## アニメーションの追加・修正

絵はすべて `scripts/generate-sprites.js` がドット単位で描いています。

1. スクリプト内にフレーム定義の関数を追加し、`ANIMATIONS` に `kind: 'action'`（シークレットなら `kind: 'secret'`）で登録する
2. `npm run sprites` を実行する

`media/sprites/` にスプライトシートと `manifest.json` が出力されます。
拡張機能側は `manifest.json` を読むだけなので、コードの変更は不要です。
ビューを開いたまま再生成しても自動で反映されます。

## スプライトの形式

`media/sprites/manifest.json` と、アニメーションごとの PNG を置きます。
PNG は、同じ大きさのコマを横一列に並べたスプライトシートです。

```json
{
  "frameWidth": 48,
  "frameHeight": 40,
  "animations": {
    "idle": { "file": "idle.png", "kind": "idle", "frames": 4, "delays": [2600, 140, 900, 140], "repeat": 1, "travel": false, "speed": 1 },
    "walk": { "file": "walk.png", "kind": "walk", "frames": 4, "delays": [160, 160, 160, 160], "repeat": 1, "travel": false, "speed": 1 }
  }
}
```

| 項目 | 意味 |
|------|------|
| `kind` | `idle`（待機・必須）/ `walk`（歩行・必須）/ `action`（ランダムに再生する演技）/ `secret`（シークレット演出） |
| `frames` | コマ数 |
| `delays` | 各コマの表示時間（ミリ秒） |
| `repeat` | 演技を何回繰り返してから待機に戻るか |
| `travel` | `true` なら、その絵のまま端まで移動する（`secret` 用） |
| `speed` | `travel` のときの、歩く速さに対する倍率 |

絵は右向きで描きます。左へ進むときは自動で左右反転します。

## デバッグ実行

1. このフォルダ（`vscode-grogu`）を VS Code で開く
2. `F5` を押す（事前に自動でコンパイルされます）
3. 新しく開いたウィンドウでエクスプローラーを開き、下部の Grogu ビューを展開する

ビューの高さは境界線をドラッグして調整できます。
ビューのタイトルをドラッグすれば、下部パネルやセカンダリサイドバーにも移動できます。

## 構成

| パス | 役割 |
|------|------|
| `src/extension.ts` | WebView プロバイダーの登録と HTML の生成 |
| `media/main.js` | 歩く・立ち止まる・ジャンプの制御 |
| `media/main.css` | レイアウトと CSS アニメーション |
| `media/sprites/` | 生成済みのスプライトシートと `manifest.json` |
| `scripts/generate-sprites.js` | ドット絵スプライトの生成 |
| `.vscode/launch.json` | F5 デバッグ用の設定 |

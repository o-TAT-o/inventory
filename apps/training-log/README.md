# training-log

筋トレ記録アプリ（仮称）。ジムで片手で入力できること、とことん軽いこと、記録を端末の外に出さないことを大事にしています。

| 場所 | 中身 |
|------|------|
| [`docs/`](docs/) | 要件定義（`requirements.md`）と、デザインの指示書（`design-brief.md`） |
| [`design/`](design/) | 画面のデザイン（キャンバスのソースと、ライト・ダークの画像） |
| [`android/`](android/) | Android 版の実装（Kotlin + Jetpack Compose + SQLDelight）。動かし方・構成は [`android/README.md`](android/README.md) |

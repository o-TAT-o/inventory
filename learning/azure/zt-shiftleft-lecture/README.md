# ゼロトラストとシフトレフト（座学資料）

社内のクラウドネイティブ勉強会「セキュリティとネットワーク」回の座学資料（60分）です。
1つのHTMLファイルだけで動き、図を動かしながら説明できます。スマホでも読めます。

## 見かた

- GitHub Pages：https://p-ota-q.github.io/inventory/zt-shiftleft-lecture/
- 手元で見る：`index.html` をブラウザで開く

`main` にpushすると、リポジトリ共通の `.github/workflows/pages.yml` が配信します。

## 構成

| 章 | 時間 | 内容 |
|---|---|---|
| 00 はじめに | 3分 | 今日のゴール、時間配分、トレイルマップでの位置 |
| 01 なぜ必要か | 10分 | 境界型とゼロトラスト、3原則、責任共有モデル、シフトレフト |
| 02 ネットワークの基本 | 12分 | VNet・NSG・Private Endpoint、名前解決、NSGのルール評価 |
| 03 リクエストの旅 | 18分 | 正常な旅8ステップ、攻撃7シナリオ、トークン改ざん |
| 04 コードの旅 | 10分 | パイプラインの関所、脆弱性対応のサイクル |
| 05 まとめ | 7分 | チェックリスト、クイズ、SC-500との対応、次回ハンズオン |

画面右上のボタンで講師メモの表示・非表示を切り替えられます（投影するときは非表示に）。

## 編集するとき

- すべて `index.html` の中にあります。
- 図やシナリオの中身は、スクリプト内の `STEPS`・`ATTACKS`・`CARDS`・`QUIZ` などの配列にまとまっています。
- ホスト名・ID・IPアドレスは説明用の例です。
